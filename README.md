# 잊혀진 신전

물망초를 따라 떠나는 작은 횡스크롤 픽셀 모험 게임입니다.
브라우저에서 바로 플레이할 수 있어요.

**▶ 플레이하기:** https://아이디.github.io/forgotten-temple/

## 이야기

햇살 마을에서 출발해 비 내리는 숲, 어둠의 동굴, 고대 유적을 지나
잊혀진 신전 깊은 곳에 잠든 "기억의 결정"을 찾아 떠납니다.

## 조작법

| 키 | 동작 |
| --- | --- |
| ← → (A / D) | 이동 |
| Z · Space · ↑ | 점프 (길게 누르면 더 높이) |
| ↓ | 나무 발판 아래로 내려가기 |
| M | 소리 켜기/끄기 |
| P · Esc | 일시정지 |

휴대폰에서는 화면에 터치 버튼이 나타납니다.

## 특징

- 구역마다 다른 분위기: 분홍빛 마을, 비 내리는 숲, 빛이 필요한 동굴, 빛줄기가 드는 신전
- 동굴에서 얻는 아이템으로 2단 점프가 열리고, 그 힘으로만 갈 수 있는 길이 생기는 탐험 구조
- 슬라임과 박쥐(밟아서 처치), 가시, 낭떠러지, 석등 체크포인트
- 물망초 33개 수집, 클리어 시간과 최고 기록 저장

## 만든 방법

- HTML 파일 하나에 HTML5 Canvas + 순수 JavaScript로 제작 (외부 라이브러리 없음)
- 캐릭터·적·아이템은 문자로 그린 픽셀 그림을 코드로 변환, 배경과 타일은 코드로 생성
- 효과음은 Web Audio API로 직접 합성
